# Frontend Developer Technical Assessment

## Overview

This repository contains a **paid frontend technical assessment**.

You have been given **selected screens from the supplied Figma design** to implement. You are **not required to implement the entire Figma design or any screens outside those specified below**.

The assessment consists of two separate frontend tasks using **Next.js, React, TypeScript, and Tailwind CSS**.

## Figma Design

https://www.figma.com/design/rIUsuHqFCqnlVgc8806my1/Untitled?node-id=0-1&p=f&t=kn9Gzgpr5Kz6Mdq2-0

---

## Task 1 — Landing Page

Implement the **selected UrbanCube landing page designs** provided for this assessment.

The selected designs include:

* Desktop landing page
* Mobile landing page
* Navigation
* Navigation states/interactions shown in the selected designs

The implementation should accurately reproduce the supplied Figma designs and be responsive across desktop and mobile screen sizes.

**Project location:** `/landing-page`

---

## Task 2 — Admin Dashboard

Implement the **selected UrbanCube admin dashboard screen** provided for this assessment.

Only the **single desktop admin view selected for the assessment** is required.

You are **not required to implement other admin screens, pages, or functionality visible elsewhere in the Figma file**.

Navigation items that reference other areas of the admin platform do not need to lead to implemented pages.

**Project location:** `/admin-dashboard`

---

## Technical Requirements

* Next.js
* React
* TypeScript
* Tailwind CSS
* Clean and reusable components
* Clear and organised project structure
* Responsive implementation of the landing page
* Navigation and states/interactions shown in the selected Figma designs
* Accurate implementation of the supplied designs
* Sensible use of TypeScript
* Maintainable and readable code

## Backend

No backend or API integration is required for this assessment.

Use **static/mock data** where data is required to reproduce the supplied designs.

## Git

Please use Git throughout the assessment and preserve your commit history.

Commit your work at sensible stages rather than submitting the entire implementation as a single final commit.

## Assessment Time

The assessment should be completed and pushed to the provided repository within **72 hours of receiving access to the repository and Figma design**.

If you encounter an issue that may prevent you from meeting the deadline, please communicate this as early as possible.

## Submission

Push your completed implementation to the provided GitHub repository before the agreed deadline.

Please also include a short note with your submission covering:

* Your approach
* How you structured your components
* Any assumptions you made
* Anything you would improve or complete with additional time

## What We Will Review

Your submission will be assessed based on:

* Accuracy to the supplied Figma designs
* Responsive implementation
* Code quality and readability
* Component structure and reusability
* TypeScript usage
* Navigation and interaction implementation
* Git commit history
* Overall frontend development practices

You may be asked to briefly walk through your implementation and explain some of the technical decisions you made.
